# MusicHub Pro

🎵 **Painel de Controle do Artista Musical**

Um aplicativo completo para gerenciar a carreira de artistas musicais independentes, centralizando streaming, redes sociais, lançamentos, conteúdo, anúncios e finanças em uma única plataforma.

## 🎯 Objetivo

Centralizar em um único lugar:
- Distribuição musical
- Redes sociais
- Plataformas de streaming
- Publicidade paga
- Estatísticas
- Receitas
- Planejamento de lançamentos

Um verdadeiro painel de controle do artista.

## ✨ Funcionalidades Principais

### 1️⃣ Dashboard Inteligente
- Visão geral de streams e crescimento
- Estatísticas de engajamento
- Receita consolidada
- Performance por país
- Top músicas

### 2️⃣ Conexão de Plataformas
Conecte suas contas de:
- **Streaming**: Spotify, Apple Music, YouTube, SoundCloud
- **Redes Sociais**: Instagram, TikTok, Facebook
- **Distribuidores**: DistroKid, TuneCore

### 3️⃣ Gestão de Lançamentos
- Agendar lançamentos
- Checklist automático
- Contagem regressiva
- Links inteligentes de pre-save

### 4️⃣ Planejamento de Conteúdo
- Calendário de posts
- Sugestões de conteúdo
- Agendamento multiplataforma
- Ideias de reels e shorts

### 5️⃣ Gestão de Anúncios
- Conectar Meta Ads e Google Ads
- Criar campanhas
- Monitorar ROI
- Otimização automática

### 6️⃣ Controle Financeiro
- Receita por música
- Gastos com anúncios
- Lucro líquido
- Projeções de crescimento

### 7️⃣ IA Insights
- Melhor horário para postar
- Momento ideal para lançamento
- Recomendações de investimento
- Estratégias personalizadas

## 🚀 Como Executar

### Pré-requisitos
- Node.js 18+ instalado
- npm ou yarn

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/okkymendes-coder/Gestor-de-p-ginas-.git
cd Gestor-de-p-ginas-
```

2. Instale as dependências:
```bash
npm install
```

3. Execute o servidor de desenvolvimento:
```bash
npm run dev
```

4. Abra no navegador:
```
http://localhost:5173
```
